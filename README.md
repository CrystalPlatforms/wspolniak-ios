# Wspólniak for iOS & iPadOS

Native iOS/iPadOS application for [Wspólniak](https://github.com/CrystalPlatforms/wspolniak) —
a private family photo-sharing service — built in SwiftUI (one universal project,
iPhone + iPad).

- **PRD**: [PRD.md](./PRD.md)
- **Distribution**: Unlisted App Store (install via owner's invitation link)
- **Status**: planning — implementation plan pending (`/carve`)

Related repositories:

| Repository | Role |
|---|---|
| `CrystalPlatforms/wspolniak` | Web app + API + backend support (Push Hub, deep-link files, install banner) |
| `CrystalPlatforms/wspolniak-ios` | This app |
| `CrystalPlatforms/wspolniak-android` | Android counterpart (Kotlin + Jetpack Compose) |
